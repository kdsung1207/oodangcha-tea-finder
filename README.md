# Today's Tea Companion

"오당차" (백다담 브랜드 연계 웹앱) 새로 만들어줘.

1. 브랜드/톤

서비스명: 오당차 ("오늘, 당신의 차 한잔"의 줄임말)

상위 브랜드: 백다담 (전통차 전문 건강음료 브랜드)

톤앤매너: 아이보리/크림 배경(#F5EEE4 계열), 진한 브라운 텍스트, 앰버/오렌지 포인트 컬러(#D98C2B 계열), 카드는 둥근 모서리(rounded-2xl)와 은은한 그림자, 굵고 감성적인 한글 디스플레이 폰트(Pretendard Bold 등). 따뜻하고 차분한 느낌.

모바일 우선 반응형 (오프라인 부스에서 참가자가 본인 스마트폰으로 접속하는 상황)

2. 랜딩 페이지

좌상단: "백다담" 로고 텍스트 + 서브카피 "오늘, 당신의 차 한잔"

중앙 "백다담" 뱃지 pill

헤드라인: "오늘, 당신의 차 한잔 / 오당차" (마지막 줄 "오당차"만 포인트 컬러)

서브텍스트: "오늘 당신에게 어울리는 차고를 찾아보세요. 몇 가지 질문에 답하면 오늘의 백다담을 추천해드려요."

메인 CTA: "오당차 시작하기 →" (검정 배경, 흰 텍스트), 옆에 "약 1분 · 6개의 질문"

하단에 김이 나는 찻잔 SVG 일러스트 + "제품 이미지 자리 · 브랜드 제공 시 교체" placeholder 배지

3. 질문 플로우 (6단계, 단일 선택, 상단 진행률 바, 이전 질문으로 돌아가기 가능)
아래 6개 질문 각각에 자연스러운 4지선다 보기를 만들어줘. 각 보기는 루이보스차/홍차/보이차/우롱차/말차/호지차/히비스커스티 7종 중 관련 차 유형에 가중치 점수를 부여하도록 설계 (카페인 민감·편안함 선호 → 루이보스·호지차, 활력·집중 필요 → 말차·우롱차, 진한 풍미 선호 → 보이차·홍차, 상큼함 선호 → 히비스커스).

내 하루의 모습은? (바쁘고 정신없는 하루 / 여유롭고 느긋한 하루 / 집중력이 필요한 업무 위주 / 사람 만날 일이 많은 하루)

가장 자주 마시는 음료는? (커피 / 탄산음료 / 물·생수 / 이미 차를 즐겨 마심)

음료를 고를 때 가장 중시하는 부분은? (건강/성분 / 맛과 향 / 편의성 / 기분 전환·힐링)

음료를 가장 많이 마시는 시간은? (아침 출근길 / 점심 식후 / 오후 나른할 때 / 자기 전 저녁)

평소 차를 잘 마시지 않는 이유는? (만드는 게 번거로워서 / 어떤 차를 골라야 할지 몰라서 / 맛이 심심해서 / 카페인이 걱정돼서)

새로운 음료를 고를 때 끌리는 맛은? (은은하고 깔끔한 맛 / 진하고 묵직한 맛 / 고소하고 부드러운 맛 / 상큼하고 새콤한 맛)

답변 선택 시 자동으로 다음 질문으로 슬라이드 전환.

4. 결과 연출 (핵심 요구사항)
6번째 질문 응답 후 결과가 바로 뜨지 않고:

물이 담긴 유리컵 일러스트 화면으로 전환

백다담 "차고"(작은 캡슐형 티 농축물) 한 알이 위에서 컵 속으로 톡 떨어지는 애니메이션

떨어진 지점부터 물속으로 색이 번지는 확산 애니메이션 — 색은 결과 차 유형에 맞게(루이보스=붉은갈색, 홍차=레드브라운, 보이차=다크브라운, 우롱차=골드/앰버, 말차=녹색, 호지차=연갈색, 히비스커스=핑크)

애니메이션 위에 "당신에게 맞는 차를 우려내는 중..." 문구

색이 컵 전체에 퍼지면 페이드인 되며 결과 화면 전환

총 연출 시간 2.5~4초, Framer Motion 사용. 우측 상단에 "건너뛰고 결과 보기" 텍스트 링크(접근성)

5. 결과 화면

"오늘의 오당차" 뱃지, "당신에게 어울리는 차고는" + 큰 글씨 차 이름 + 한 줄 감성 카피

제품 이미지 placeholder

"왜 이 차고를 추천했을까요?" — 선택 답변 패턴 근거로 2~3문장 동적 추천 이유

우상단 "다시 테스트하기" 링크

6. 차고 사용법 4단계
"차고가 처음이라면? 물을 넣으면 바로 마시는 차. 딱 4단계예요."

차고를 컵에 넣기 2. 물 넣기 3. 녹이기 4. 마시기 (각 카드 아이콘 placeholder 포함)
하단 버튼: "이 차고 마셔보기 →"(백다담 공식몰 링크, 변수로 분리) / "다른 차고도 비교해보기"

7. 다회 소개팅 타임슬롯 신청 (신규 추가)
결과 화면 바로 아래에 섹션 추가:

제목: "오당차 결과로 다회 매칭 신청하기"

설명: "같은 취향의 사람들과 짧은 다회 소개팅을 즐겨보세요. 참여 가능한 시간대를 선택해주세요."

시간대는 변수 리스트로 관리 (예: 13:00 / 14:00 / 15:00 / 16:00 — 실제 운영 시 개수/시간 조정 가능하게)

각 시간대는 버튼/카드 형태로 표시하고, 슬롯별 정원(예: 슬롯당 8명)을 두어 정원 도달 시 "마감" 배지 표시 및 선택 비활성화

시간대 선택 후 간단한 입력폼: 이름, 연락처(전화번호 또는 인스타그램 핸들 중 선택 가능한 텍스트 입력)

제출 시 사용자의 오당차 결과(차 유형)와 이름/연락처/선택 시간대를 함께 저장

제출 완료 시 "신청 완료! OO시 타임 참여자 명단에 등록되었어요." 확인 메시지와 함께 신청 내역 요약 카드 표시

백엔드는 Supabase 연동으로 처리해줘 (Lovable 기본 제공 연동 사용): signups 테이블에 name, contact, tea_result, timeslot, created_at 저장

운영진이 신청 현황을 볼 수 있도록 간단한 관리자 페이지(/admin 라우트, 비밀번호 하나로 간단 보호)를 만들어서 시간대별 신청자 목록을 테이블로 보여주고 CSV로 내보내기(다운로드) 할 수 있게 해줘 — 현장에서 시간대별로 소개팅 그룹을 짤 때 바로 활용

8. 쿠폰 발급
"신규 고객 전용 쿠폰 — 오늘의 추천 차고 10% 할인" 카드. 쿠폰 코드(placeholder) + "쿠폰 받기" 버튼(클릭 시 클립보드 복사 + 토스트 메시지).

9. 짧은 만족도 질문
"차고를 처음 접했을 때, 어떻게 먹는 제품인지 이해하기 쉬웠나요?" 1~5점 버튼, 선택 시 감사 문구 표시.

10. 결과 공유
"내 오당차 결과 공유하기" — 공유 카드 미리보기(브랜드명, 뱃지, 결과 차 이름/카피, 공유 URL) + "공유하기" / "공유 카드 저장(이미지)" / "링크 복사" 버튼.

기술 요구사항

React + Tailwind + Framer Motion, Supabase 연동(타임슬롯 신청 데이터 저장 및 정원 카운트용)

6개 질문 답변 기반 점수 계산 로직은 별도 함수로 분리해서 나중에 가중치 조정 쉽게

전체 플로우: 랜딩 → 질문 1~6 → 로딩/애니메이션 → 결과 → 다회 타임슬롯 신청 → 사용법 4단계 → 쿠폰 → 만족도 → 공유, 한 페이지 스크롤 형태 (질문 단계만 풀스크린 오버레이)

관리자 페이지(/admin)는 참가자용 플로우와 분리된 별도 라우트로 구성
