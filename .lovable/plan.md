# 오당차 웹앱 구현 계획

## 참가자 경험
- 아이보리·브라운·앰버 색감의 모바일 우선 랜딩을 구성합니다.
- 6개 질문을 전체 화면 흐름으로 만들고, 선택 즉시 다음 질문으로 전환합니다.
- 답변별 차 가중치는 별도 데이터와 계산 함수로 분리합니다.
- 마지막 답변 뒤 캡슐이 유리컵에 떨어지고 결과 색이 번지는 3초대 연출을 구현합니다.
- 결과와 추천 근거, 신청, 사용법, 쿠폰, 만족도, 공유 기능을 한 페이지에 이어 배치합니다.

## 신청과 관리자
- 13:00·14:00·15:00·16:00 시간대를 변수로 관리하고 각 정원을 8명으로 제한합니다.
- 이름, 연락처, 추천 차, 시간대를 Lovable Cloud에 저장합니다.
- `/admin`에 서버 검증 비밀번호 화면, 시간대별 참가자 표, CSV 다운로드를 만듭니다.
- 참가자 개인정보는 브라우저에서 직접 읽을 수 없게 유지합니다.

## 기술 세부
- TanStack Start, React, Tailwind CSS, Framer Motion을 사용합니다.
- 입력값을 브라우저와 서버 양쪽에서 검증합니다.
- 관리자 세션은 서명된 보안 쿠키로 유지합니다.
- 각 화면에 고유한 제목과 공유 설명을 설정합니다.

## 확인
- 주요 참가자 흐름과 관리자 로그인을 실제 화면에서 점검합니다.
- 모바일과 데스크톱 크기에서 겹침, 잘림, 동작 오류를 확인합니다.
